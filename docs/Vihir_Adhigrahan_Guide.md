## ३. वापरण्याची पद्धत

### अ) HTML पान (सर्वात सोपे)

1. `Vihir_Adhigrahan.html` Chrome मध्ये उघडा (पहिल्यांदा इंटरनेट लागते).
2. **पायरी १** — Excel फाईल निवडा. टेम्पलेट हवे असल्यास *"रिकामे Excel टेम्पलेट डाउनलोड"*.
3. **पायरी २** — यादी तपासा. अपूर्ण नोंदीसमोर **⚠ अपूर्ण** दिसते. *"पहा"* ने २५ पाने पाहता येतात.
4. **पायरी ३** — हव्या त्या नोंदी निवडा → *"निवडलेल्यांच्या PDF (ZIP)"*.

**दोन प्रकारे PDF:**

| पद्धत | केव्हा वापरावी | आकार | गुणवत्ता |
|---|---|---|---|
| ZIP बटण | अनेक लोक एकदम | ~२.५ MB / व्यक्ती (सामान्य) | प्रतिमा स्वरूपात, वाचनीय |
| पहा → प्रिंट → *Save as PDF* | एक महत्त्वाची फाईल | ~२३० KB | सर्वात स्पष्ट (vector) |

गुणवत्ता पर्याय: सामान्य (~२.५ MB), उच्च (~४ MB), छपाईसाठी सर्वोत्तम (~९ MB). एका व्यक्तीला अंदाजे ५ सेकंद लागतात.

### ब) Python स्क्रिप्ट

```bash
# एकदाच
pip install openpyxl playwright
python -m playwright install chromium

# वापर
python generate.py                    # Vihir_Data.xlsx → output/ फोल्डर
python generate.py "Badnapur.xlsx"    # दुसरी Excel फाईल
python generate.py --blank            # रिकामा फॉर्म
```

PDF चे नाव: `001_गाव_मालकाचेनाव.pdf`. Python आवृत्तीत सर्व PDF vector (लहान व स्पष्ट) असतात.
